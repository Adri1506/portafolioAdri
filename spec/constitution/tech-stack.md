# Tech Stack — Portafolio Adrián Zamorano

## Stack Propuesto

| Capa | Tecnología | Razón |
|------|-----------|-------|
| **Framework** | Next.js 14+ (App Router) | Stack que Adrián domina, usado en sus 3 proyectos en producción |
| **Estilos** | Tailwind CSS | Misma razón, consistencia con proyectos existentes |
| **Lenguaje** | TypeScript | Tipado seguro, estándar en proyectos modernos |
| **Deploy** | Vercel (plataforma actual) | Sin costo, integración nativa con Next.js |
| **Fuentes** | Google Fonts / next/font | Rendimiento, variedad tipográfica |

## Stack Descartado

| Tecnología | Razón |
|-----------|-------|
| Astro | Bueno para portafolios simples, pero limita interactividad que podríamos necesitar |
| React plano | Next.js ofrece routing, SSR/SSG, optimización out-of-the-box |
| SPA puro | Peor SEO, peor experiencia inicial |

## Dependencias estimadas

- next, react, react-dom
- tailwindcss, postcss, autoprefixer
- framer-motion (animaciones)
- lucide-react / heroicons (iconografía)
- next/font (tipografía)
